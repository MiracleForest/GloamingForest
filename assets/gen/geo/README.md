# assets/gen/geo

Generated by `tools/models/convert.ps1` and `tools/models/attachable.ps1` (unit F2): Bedrock geometry, bone maps
and base animations converted from The Gloaming Forest's Java entity models, partitioned by owner into
`<unit>/rp/**` (rule R3). **Never edit these files by hand**: regenerate them with the tool (`-Unit <unit>`), or
override a file with a manual one of the same id under `assets/pack/rp/**` (the manual layer wins).
