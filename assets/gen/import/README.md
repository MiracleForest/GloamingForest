# assets/gen/import

Generated by `tools/import/run.ps1` (unit F1) from the shared Twilight Forest checkout: textures, models,
blockstates, lang, tags, loot tables, recipes, advancements, worldgen and other data, partitioned by owner
into `<unit>/{bp,rp,data,lang}/**` (rule R3). **Never edit these files by hand**: regenerate them with
`pwsh tools/import/run.ps1 -Unit <unit>` and change the result through `tools/import/overrides/<unit>.json`, or
override a file with a manual one of the same id under `assets/pack/**` (the manual layer wins).

The textures, models and lang come from The Twilight Forest under CC BY-NC-SA 4.0
(see [assets/LICENSE](../../LICENSE) and [NOTICE](../../../NOTICE)). TF's sounds, music and structure templates
are All Rights Reserved and are never imported.
